# 数据与同步

## 本地优先

Squitle 在未登录状态下即可完整使用。所有修改先形成版本化 `ScheduleDocument` 并写入本地；启用同步只增加远端副本，不改变本地文档的所有权。

一个账号可以保存多个 TimeLine。每个文档使用稳定的 `documentId`，本地修订号和远端修订号相互独立。

## 同步状态机

| 本地变化 | 远端变化 | 结果 |
|---|---|---|
| 无 | 无 | 保持当前状态 |
| 有 | 无 | 条件上传 |
| 无 | 有 | 下载远端版本 |
| 有 | 有 | 停止自动覆盖并进入冲突处理 |

首次连接空远端时上传本地文档；发现不同远端文档时由用户选择保留哪一份。上传携带预期远端修订号，服务端只接受匹配的条件写入。

## 同步提供方

### Squitle 云端

通过 ChatGPT/Sites 身份确定用户，只同步该用户自己的设备。服务端使用 D1 保存文档和单调递增的远端修订号。

### WebDAV 与坚果云

WebDAV 地址、用户名和应用密码保存在当前设备。浏览器把请求发送到同源代理，再由服务端访问 HTTPS WebDAV 地址，避免把认证头直接发送到第三方页面上下文。

### CloudBase

CloudBase 适配器目前作为可选同步实现保留，不是网站运行的前置条件。公开环境配置来自 `.env`，管理凭据不得进入客户端变量或 Git。

## 备份与迁移

- 文档包含 `schemaVersion`，旧版本通过单向迁移读取。
- JSON 导出用于跨环境迁移和人工备份。
- 同步冲突会保留副本，避免静默覆盖。
